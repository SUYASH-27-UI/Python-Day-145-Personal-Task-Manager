# Python Day 145 - Personal Task Manager

## Description
A Python-based Personal Task Manager that allows users to organize daily tasks and save them in a JSON file.

## Features
- Add new tasks
- Display all tasks
- Mark tasks as completed
- Display pending tasks
- Delete tasks
- Save task information permanently

## Files
- `task_manager.py` - Main Python program
- `tasks.json` - Task storage file

## How to Run
Keep both files in the same folder.

Run the command:

`python task_manager.py`

## Concepts Used
- JSON File Handling
- Lists and Dictionaries
- Functions
- CRUD Operations
- Exception Handling
- List Comprehensions
